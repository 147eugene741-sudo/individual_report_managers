# Individual Report Generator

Генератор индивидуальных отчётов по итогам оценки сотрудников (360 градусов).

## 📋 Описание

Проект предназначен для автоматической генерации HTML-отчётов на основе данных из Excel-файлов с оценками сотрудников (самооценка, оценка руководителем, оценка коллегами, оценка подчинёнными).

### Основные возможности

- **Парсинг Excel-файлов** с оценками компетенций и открытыми вопросами
- **Объединение данных** из нескольких источников (self, manager, colleagues, subordinates)
- **Интеграция с AI-оценками** кейсов через отдельные Excel-файлы
- **Генерация HTML-отчётов** с интерактивными графиками (Chart.js)
- **Расчёт средних оценок** по soft-skills блокам
- **Генерация выводов и рекомендаций** на основе оценок
- **Анализ поведенческих паттернов** по 4 блокам компетенций
- **Экспорт** одного автономного HTML-файла на сотрудника (можно отправить руководителю как есть)

## 🚀 Быстрый старт

### Требования

- Python 3.8+
- Зависимости: `openpyxl`, `jinja2`, `pandas`, `flask`

### Установка

```bash
cd individual_report
pip install -r requirements.txt
```

### Запуск генерации отчётов

```bash
python main.py
```

Или с указанием путей к данным и выходной папке:

```bash
python main.py /path/to/data /path/to/output
```

### Запуск Flask-сервера (опционально)

```bash
python app.py
```

Сервер будет доступен по адресу `http://127.0.0.1:5000`

## ⚙️ Конфигурация

Все настройки находятся в файле `config.json`:

### soft_block_map
Маппинг компетенций по блокам для группировки в отчёте:
- Личная эффективность и исполнение
- Мышление и принятие решений
- Взаимодействие и коммуникации
- Лидерство и развитие команды

### parser
Настройки парсера Excel:
- `competencies_section_text` - маркер начала раздела компетенций
- `soft_instruction_text` / `hard_instruction_text` - маркеры разделов soft/hard навыков
- `open_questions_section_text` - маркер раздела открытых вопросов
- `meta_*_label` - метки для извлечения метаданных (ID, ФИО, дата)
- `*_column_label` - названия колонок для разных типов оценок
- `stop_phrases_for_instruction` - фразы для пропуска инструкций
- `exclude_keywords` - ключевые слова для исключения строк

### ai
Настройки интеграции с AI-оценками:
- `file_pattern` - шаблон имени файла с AI-оценками
- `columns` - названия колонок в AI-файле

## 📊 Формат входных данных

### Excel-файлы с оценками

Файлы должны содержать:
1. **Метаданные** в первых строках (ID опроса, Оцениваемый, Дата, Имя опроса)
2. **Раздел компетенций** с колонками: Название компетенции, Самооценка, Руководитель, Коллеги
3. **Раздел открытых вопросов** с вопросами и ответами

Тип формы определяется по заполненным оценкам (1–4), а не только по имени опроса:
- заполнена только «Самооценка» — файл относится к самооценке;
- заполнены самооценка и ровно одна чужая роль (руководитель / коллеги / подчинённые) — файл относится к этой роли, читается только её колонка;
- заполнены две или более чужие роли — файл пропускается, предупреждение выводится в конце обработки.
Если по оценкам тип не определяется, используется имя опроса.

### AI-файл (опционально)

Excel-файл с паттерном имени `*eval*.xlsx`, содержащий колонки:
- ФИО сотрудника
- ID кейса
- Класс поведения
- Позитивные паттерны

## 📈 Генерируемые отчёты

Для каждого сотрудника в `output/` создаётся **один** HTML-файл с именем по ФИО, например `Иванов Иван Иванович.html`.

Файл автономный: данные, стили и логика вшиты в HTML, Chart.js и SheetJS подгружаются с CDN. JSON и папка `vendor` рядом не создаются. При повторной генерации файл с тем же ФИО перезаписывается.

Руководитель открывает файл в браузере (нужен интернет для графиков и выгрузки Excel), заполняет форму калибровки и скачивает Excel кнопкой «Сохранить изменения и скачать».

### Разделы отчёта

1. **Графики** - визуализация soft и hard компетенции по источникам оценок
2. **Выводы** - текстовые рекомендации на основе средних оценок
3. **Таблица оценок** - детальная таблица всех компетенций
4. **Кейсы** - разбор ситуационных кейсов с AI-анализом
5. **Performance Review** - форма для заполнения целей и задач
6. **Итоговая оценка** - финальная оценка и обоснование

## 🔧 Расширение функциональности

### Добавление новых компетенций

Отредактируйте `soft_block_map` в `config.json`, добавив новые компетенции и их привязку к блокам.

### Изменение шаблона отчёта

Отредактируйте `templates/report.html`. Шаблон использует Jinja2 и передаёт следующие переменные:
- `employee`, `manager`, `colleagues` - метаданные
- `soft_skills`, `hard_skills` - оценки компетенций
- `soft_blocks` - сгруппированные блоки soft компетенции
- `cases` - ситуационные кейсы
- `performance` - данные performance review
- `soft_recommendations` - текстовые выводы
- `behavioral_patterns` - поведенческие паттерны

### Настройка сценариев рекомендаций

Измените логику в функциях `_get_soft_skills_recommendation()` и `_get_behavioral_patterns()` в `backend/merge.py`.

## 🐛 Известные ограничения

- Требуется наличие полного набора файлов (self, manager, colleagues) для каждого сотрудника
- Подчинённые (subordinates) - опциональный источник оценок
- AI-оценки загружаются только из первого найденного файла `*eval*.xlsx`
- При наличии нескольких файлов одного типа используется последний найденный
- Формы с оценками сразу нескольких ролей (кроме самооценки) не обрабатываются
