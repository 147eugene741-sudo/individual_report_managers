# individual_report

Система для создания индивидуальных отчётов по итоговой калибровке менеджеров.

## Описание

Проект предназначен для автоматизированной генерации отчётов на основе данных из Excel-файлов с оценками компетенций сотрудников (360 градусов). Система обрабатывает файлы самооценки, оценки руководителя и коллег, объединяет их с AI-анализом кейсов и генерирует интерактивные HTML-отчёты.

## Структура проекта

```
individual_report/
├── main.py              # Основной скрипт обработки данных
├── app.py               # Flask-приложение для сохранения отчётов
├── config.json          # Конфигурация (маппинг компетенций, настройки парсера)
├── requirements.txt     # Зависимости Python
├── backend/             # Модули парсинга, объединения и утилит
├── templates/           # HTML-шаблоны отчётов
├── static/              # Статические файлы (CSS, JS, логотипы)
│   └── vendor/          # Локальные копии Chart.js и xlsx (в отчёт не копируются)
├── data/                # Входные Excel-файлы
├── output/              # Автономные HTML-отчёты (`ФИО.html`)
├── logs/                # Логи работы приложения
└── results/             # Сводная таблица Excel
```

## Требования

- Python 3.8+
- Зависимости из `requirements.txt`

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Генерация отчётов

Запуск основного скрипта для обработки Excel-файлов из папки `data/`:

```bash
python main.py
```

Или с указанием кастомной папки с данными:

```bash
python main.py /path/to/data_folder
```

### Запуск Flask-приложения

Для сохранения отчётов через веб-интерфейс:

```bash
export FLASK_DEBUG=True  # Опционально: режим отладки
export FLASK_PORT=5000   # Опционально: порт
python app.py
```

Приложение будет доступно по адресу `http://127.0.0.1:5000`.

#### API Endpoints

- `POST /save_report` — Сохранение данных отчёта в Excel
- `GET /reports/<filename>` — Получение сгенерированного HTML-отчёта
- `GET /health` — Проверка статуса приложения

## Конфигурация

Файл `config.json` содержит:

- **soft_block_map** — Маппинг soft компетенции по блокам компетенций
- **parser** — Настройки парсера Excel (текстовые маркеры, ключевые фразы)
- **ai** — Параметры для загрузки AI-оценок (паттерн файлов, названия колонок)
- **file_types** — Типы файлов оценок: `self`, `manager`, `colleagues`

## Формат входных данных

В папку `data/` необходимо поместить Excel-файлы со следующими типами оценок для каждого сотрудника:
- Самооценка (`self`)
- Оценка руководителя (`manager`)
- Оценка коллег (`colleagues`)

Опционально: файл с AI-анализом кейсов (имя файла должно содержать `eval`).

## Выходные данные

Для каждого сотрудника в папке `output/` создаётся один файл:
- `Иванов Иван Иванович.html` — автономный HTML-отчёт (данные и JS внутри, Chart.js и xlsx с CDN). JSON и `vendor` не создаются. При совпадении ФИО файл перезаписывается.

## Логирование

Логи сохраняются в папку `logs/`:
- `main.log` — Логи основного скрипта обработки
- `app.log` — Логи Flask-приложения

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `CONFIG_PATH` | Путь к файлу конфигурации | `config.json` |
| `TEMPLATES_DIR` | Папка с HTML-шаблонами | `templates/` |
| `STATIC_DIR` | Папка со статикой | `static/` |
| `DATA_DIR` | Папка с входными данными | `data/` |
| `OUTPUT_DIR` | Папка для выходных файлов | `output/` |
| `FLASK_DEBUG` | Режим отладки Flask | `False` |
| `FLASK_PORT` | Порт Flask-приложения | `5000` |
| `FLASK_HOST` | Хост Flask-приложения | `127.0.0.1` |
